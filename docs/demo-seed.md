# 雨夜档案：旧钟楼的灯

临海城连续下了三天雨。旧钟楼在午夜后会亮起一盏不属于任何人的灯，灯光每亮一次，城里就会有一段记忆被人遗忘。

## 人物

- **沈砚**：档案馆管理员，擅长从旧文件中找出被删改的时间线。他记得一位已经不存在的妹妹。
- **林澄**：电台夜班主持人，能在收音机的杂音里听见未来十分钟的声音，但每听见一次，就会忘记一件童年的小事。
- **钟表匠顾野**：住在钟楼下方的修表铺，坚称那盏灯是给“还没有回来的人”留的。

## 世界规则

1. 午夜后的钟楼只允许一个人进入。
2. 被灯光照到的物件会显示它最后一次被使用的场景。
3. 如果有人在钟声响起前说出一个人的全名，那个人会从所有人的记忆里消失。

## 开场线索

雨夜十二点，沈砚在档案馆收到一盘没有标签的录音带。录音里先是林澄十分钟后的声音，随后传来钟表匠顾野的低语：“不要让她听见第十三声。”

沈砚带着录音带赶到钟楼时，林澄已经站在门口。钟楼里传来第十二声钟响，门后的灯刚刚亮起。
